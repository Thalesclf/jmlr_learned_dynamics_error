# Original inputs

The Lorenz-96 and Kuramoto-Sivashinsky reference trajectories used in this study are generated by the simulation code (`src/realized_error/systems.py`), so no raw input data are stored here. The original PyTorch checkpoints and the results of the campaigns run with them are distributed as two archives attached to release v1.0.0 and are restored to their original paths with `scripts/restore_legacy_data.py` (see `docs/DATA_RELEASE.md`).

The saved results used by the manuscript are in `results/current/`.
